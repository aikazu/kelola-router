# v0.12 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.12 — wire the Biome linter, add `docs/roadmap.md`, refresh README + CLAUDE.md, bump versions, tag the release.

**Architecture:** Wrap-up release for the already-merged model-aliases feature. No new runtime code. Adds two Biome config files (root + client), a roadmap doc, version bumps, and a git tag. Six small commits.

**Tech Stack:** @biomejs/biome 2.4.16 (already in devDeps), Hono, Vite, vitest.

**Pre-existing blocker (NOT in this release):** On Windows, `src/db/index.ts:21` uses `dbPath.lastIndexOf("/")` to find the parent dir. Windows paths use `\`, so `lastIndexOf` returns `-1` → `dbPath.substring(0, -1)` = `""` → `mkdir("")` fails. This blocks `npm test` on Windows. **Fix separately (out of scope for v0.12).** Use `path.dirname(dbPath)` or split on both separators. Verification in this plan assumes macOS/Linux OR a pre-fix `db/index.ts`. See "Out of scope" note in Task 6.
