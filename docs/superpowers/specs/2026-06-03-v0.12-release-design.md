## Decisions

### Linter: Biome (single tool, lint+format)

- Already in devDependencies (`@biomejs/biome ^2.4.16`) but unconfigured
- Replaces need for ESLint + Prettier
- One config per package (root for server, `client/` for SPA)
- VCS-aware (uses git)
- No new dependencies

### Version: align `package.json` to tag scheme

- Current state: tags use `v0.<N>` (v0.2..v0.6, v0.12-model-aliases); `package.json` uses semver-style `0.2.0` and `client/package.json` uses `0.0.1`
- Decision: bump both `package.json` files to `0.12.0` to match the tag scheme
- README badge already uses the tag scheme (`v0.11`); will become `v0.12`

### Roadmap: new `docs/roadmap.md`, newest first

- Standalone file, linked from README
- Sections per released version (v0.12, v0.11, v0.10, v0.9)
- **Next up** placeholder section at top for v0.13+ ideas

### Commit strategy

Per CLAUDE.md "commit after every meaningful change":

1. `chore(deps): wire Biome linter (root + client configs, lint scripts)`
2. `chore: biome auto-format`
3. `docs(roadmap): add docs/roadmap.md with v0.12 + history`
4. `docs(readme): v0.12 — aliases feature, badge bump, roadmap link`
5. `chore(release): v0.12 — bump package.json versions, refresh CLAUDE.md version refs`
6. `git tag -a v0.12 -m "v0.12 — model aliases + Biome linter + doc polish"`

No `git push` — user policy is "never push without asking".

## File-level changes

### `biome.json` (new, root)

Covers `src/`, `tests/`, `scripts/`, and root `*.ts`/`*.tsx`/`*.js` (e.g. `vitest.config.ts`, `vitest.setup.ts`). Excludes `client/`, `dist/`, `node_modules/`.

```json
{
  "$schema": "https://biomejs.dev/schemas/2.4.16/schema.json",
  "vcs": { "enabled": true, "clientKind": "git", "useIgnoreFile": true },
  "files": {
    "includes": ["src/**", "tests/**", "scripts/**", "*.ts", "*.tsx", "*.js"],
    "ignore": ["dist/**", "node_modules/**", "client/**", "*.db", "*.db-*"]
  },
  "formatter": {
    "enabled": true,
    "indentStyle": "space",
    "indentWidth": 2,
    "lineWidth": 100,
    "lineEnding": "lf"
  },
  "javascript": { "formatter": { "quoteStyle": "single", "trailingCommas": "es5", "semicolons": "always" } },
  "linter": {
    "enabled": true,
    "rules": {
      "recommended": true,
      "style": { "noExplicitAny": "error", "useImportType": "error" },
      "suspicious": { "noConsoleLog": "warn", "noDebugger": "error" }
    }
  }
}
```

### `client/biome.json` (new)

Covers `client/src/**` and `client/**/*.{ts,tsx}`. Same formatter; linter uses `recommended` only for v0.12 (Biome's `recommended` already covers Preact JSX basics — `noReactSpecificRules` and similar knobs are deferred).

```json
{
  "$schema": "https://biomejs.dev/schemas/2.4.16/schema.json",
```

## Risk

- **Biome config drift:** If Biome flags existing code, `lint:fix` will reformat files. Auto-format commit (`chore: biome auto-format`) makes the diff trivially revertable if it breaks tests.
- **JSX rule gaps on client:** v0.12 uses `recommended` only for client; React-specific rules deferred. Will be incomplete lint coverage on client until v0.13+.
- **Version drift between tags and `package.json`:** Future releases should bump `package.json` at the same time as the tag to avoid the same confusion this release resolves.
